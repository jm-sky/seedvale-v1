# Historical voice donor evidence

The V1 [casting](../../design/npc-voices/CASTING.md) and
[catalog](../../design/npc-voices/CATALOG.md) are the permanent owners.

- `docs/`: historical Fish production notes, generation history, interaction/greeting drafts and replacement notes.
- `reviews/`: historical donor dialogue review.
- `named-references/`: 38 QC reference paths; six aliases point to identical retained recordings through relative symlinks. Never runtime candidates.
- `rejected-speakers/`: 38 Brian British clips, globally excluded; retained solely for provenance/QC.
- `backups/`: six unique merchant takes; filename alone does not identify their UUID or establish replacement eligibility. No runtime paths used them.
- `qc-config-2026-11-05/`: exact configuration bytes pinned by historical identity audit hashes.
- [Original V1 catalog](v1-catalog-before-consolidation.md): unmerged historical wording and annotations.

No uncertain audio was deleted. British-female named reference evidence is
archived even though that voice is rejected from the playable set. Historical
JSON paths describe the original source tree; the migration inventory resolves
them. Other V3 archives remain untouched.
