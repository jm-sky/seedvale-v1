# Implementation notes — Jumpable low campfire collision

[Plan](../settlements-024-campfire-jumpable-low-collision.md) · Source reviewed at `c78db12c`.

## Registration and data contract

- `src/settlement/props.ts` already places the visual on the terrain and stores a world-space `Vector3(fireX, sampleHeight(fireX, fireZ), fireZ)` in `landmarks.campfire.position`. `villagePlan.ts:plannedCampfireBodyKind` selects the variant. In `settlementPropColliders.ts`, require `y` on the **campfire position only**. Existing unit fixtures supply only XZ. Do not silently substitute zero.
- `propSpecs.ts` owns the existing radii, 0.60 m for the default pit and 1.15 m for masonry. Put fixed body-clearance heights beside them. Use 0.34 m and 0.30 m respectively. The shipped `public/models/settlement/campfire_unlit.glb` has one uniformly scaled mesh node. Across its POSITION accessor bounds, the Y span is 4520 and the longest span (X) is 16383. `assets/loadGltf.ts:preparePropFitMax` grounds and fits it to 1.2 m, giving a solid top of about 0.331 m. Rounding up covers the wood as well as the lower stone ring. In `campfireProps.ts` the fallback pit stones reach about 0.20 m and the masonry lip is 0.28 + 0.02. Use the same pit proxy for loaded and fallback visuals. Flame, fuel, light and grate state do not determine these numbers.
- `createSettlement.ts` registers the complete current collider array under `def.id` and clears it on release. Set the top once in the existing circle literal. No second registry entry, per-frame terrain lookup, mesh bounds, save field or disposal hook.
- `app/worldBundle.ts` creates/restores `createPlacedFires` with scene, height sampler, saved fires, audio and light budget. `settlement/PlacedFires.ts` owns visuals, fuel and despawn, with no collider registration. Its simple/pit/pile and habitat burns stay out of this change. Decorative world remains are separate from the village landmark.

## Player-only clearance

- `world/collision.ts:colliderActiveAtY` has inclusive world-space bounds shared by actors. A generic `minY = baseY` frees a walker approaching from slightly below the base. A generic `maxY` also frees actors whose current ground is above the lip. In particular `ai/NpcAgent.ts:collidersNearAtHeight` uses **current mesh Y** even for remote walkability/steering probes. `fauna/AnimalAgent.ts:isWalkable` filters candidate XZ using current mesh Y before `colliderContainsPoint`. Keep their existing disk and cave semantics.
- Add one optional absolute clearance top on `CircleCollider` (e.g. `jumpClearanceY`). Leave the fire's shared vertical envelope unset. Keep the existing player height filter for all colliders, then skip a marked circle only when the player is airborne and current feet Y is **strictly above** its top. An omitted marker preserves old behavior. A small pure player predicate can own the composed rule and be called within the existing filter. Do not tag entities by radius or change the registry or resolver.
- `player/PlayerController.ts:update` resolves candidate XZ with the current feet Y before calling `updateVerticalMotion(dt)`. Both the audited trace branch and `resolveHorizontalMove` (also used by `gapClose`) use `collidersNearAtHeight`. Keep that single query seam, resident-ground gating, cave containment order and water handling. A jump request on the first tick is not clearance. A descending overlap resolves on the next horizontal movement that sees active collision. No support surface or push while stationary is required.
- `player/verticalMotion.ts` uses semi-implicit gravity 20 m/s² and nominal apex 0.60 m. `playerDimensions.ts` gives a 0.35 m player radius. A centred crossing must travel **1.90 m** (pit) or **3.00 m** (masonry) while clear. At 60 Hz, the default 8 m/s walk covers about 2.40 m above 0.34 m and 2.53 m above 0.30 m. Use normal movement for pit and the existing 1.8× sprint for the centred masonry fixture. A review harness using V1's integrator and XZ resolver, starting at the contact rim on level terrain, confirmed those crossings at 30 and 60 Hz with the proposed clearance rule. It did not load the controller or the game.
