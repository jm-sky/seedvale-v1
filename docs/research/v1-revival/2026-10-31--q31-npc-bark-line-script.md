## 1. Landed contract (code, behaviour-neutral with current assets)

- New voice intents: `weather_shelter_rain`, `weather_shelter_storm`, `weather_shelter_snow` (`NpcVoiceSemanticIntent`, `src/ai/npcVoiceLines.ts`). `weather_shelter` now means **weather-neutral text only**.
- The bark request carries `weather` (`NpcBarkRequest.weather`, set from `NpcAgent.currentWeather` in `beginSeekShelter`). `resolveNpcBarkVoiceUrl` tries, in order (`weatherShelterVoiceIntents`, `src/ai/npcBarkRequest.ts`):
  - rain → `weather_shelter_rain` → `weather_shelter`
  - storm → `weather_shelter_storm` → `weather_shelter_rain` → `weather_shelter` (storm may reuse rain lines, author 2026-10-30)
  - snow → `weather_shelter_snow` → `weather_shelter` (never a rain line)
  - none → `weather_shelter`
  Each intent walks the normal scope hierarchy (`npc:` → profession(+age) → general(+age)) before the next intent, so **weather correctness beats role identity**: a guard in snow prefers a general snow line to a guard line naming the wrong weather.
- Throttling is unchanged: limiter policy, cooldowns and budgets stay keyed by the request intent `weather_shelter`; the variant only picks the clip. No new trigger, no new per-frame work.
- Manifest: the male/guard `*_weather_shelter_01.mp3` files ("Rain's coming down hard…") are re-keyed as `weather_shelter_rain` (filenames kept); `general_female_weather_shelter_01.mp3` ("This weather's getting worse…") stays neutral. Result today: rain/storm male/guard → rain clip, snow male/guard → silence, female → neutral clip — identical to the interim F1 behaviour, which the fallback chain now replaces (`weatherShelterBarkAllowed` removed).
- Tests: `src/ai/npcBarkLimiter.test.ts` (variant order, current-asset behaviour, single policy), `src/ai/npcVoiceLines.test.ts` (re-keyed rain clip).

## 4. Proposal — weather remarks without shelter behaviour (author decision)

Today only `seekShelter` start triggers a weather bark; fog, cloudy, light rain (intensity ≤ 0.55) and cold-but-dry weather produce none (`weatherShelterPressure` = 0). Options:

- **(a) No new trigger** [recommended for now] — batch A–C first; Q30 dedup lands; listen in game, then decide.
- **(b) Ambient weather remark** — a new optional bark intent `weather_remark` fired at most once per NPC per weather episode when the NPC is idle/working outdoors and the weather type changed recently (fog rolls in, light rain starts, sky clears after rain, first snow). Needs: a weather-change edge per NPC (already forwarded once per frame as `currentWeather`), a new limiter policy (optional budget, long cooldown), lines per weather type. Presentation-only, but it is **new trigger semantics** → author choice.
- **(c) Campfire weather conditioning** — recon §6.3: choose `campfireTalk` weather exchanges only when compatible with the real weather (data change at the pairing call site). Independent of (b).
