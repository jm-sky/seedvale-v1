## Summary

Wolves keep coming up to the settlement and attacking people. Anna thinks the cause is a nearby den, so killing single wolves is not enough. The player must destroy the den (spawn point) for good.

## Stages / objectives

- Destroy the wolf den spawn point (`destroy_spawn_point`, `WOLF_DEN_ID`).

## Outcomes & rewards

- `reported` (complete): relation +2 with Anna, reputation competence +20, courage +22, benevolence +8, and renown +35. No item reward.
