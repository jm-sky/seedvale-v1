## Binding visual direction

- Renaissance artisan notebook / Leonardo-inspired hand-drawn inventory illustrations.
- Monochrome pencil and ink treatment; graphite, warm dark-brown/sepia linework, and no painterly colour fills.
- Darker, decisive outer contours for small-scale legibility, while interior surfaces remain lightly constructed with thin graphite strokes, restrained cross-hatching and subtle sketch marks.
- Recognisable medieval forms and grounded materials; no exaggerated fantasy glow, saturated pigments, polished 3D render style or photorealism.
- The approved sheet is a **visual-style reference**, not a production atlas, final UI layout or a decision to burn parchment into each item image.
- **Approved background:** an irregular semi-transparent parchment patch around each item, fading into fully transparent surrounding pixels. Avoid rectangular cards. Verify genuine PNG alpha.
- Exact output resolution, tier treatment and image composition remain pilot questions.
- The existing SVG icon mapping remains untouched.
