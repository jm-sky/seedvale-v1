## Summary

Anna needs five branches to repair the shared pasture fence. The quest is offered only after the player has resolved `sporne-drewno` in Anna's favour, or has delivered wood to Piotr in `drewno-dla-piotra`. If the fence is already repaired, the quest ends as `already_repaired`.

## Stages / objectives

- Gather 5 `branch` items (`gather_item`, count 5).

## Outcomes & rewards

- `delivered_to_anna` (complete, hidden reward): 3 carrot seeds and relation +1 with Anna.
- `already_repaired` (complete): no reward.
