## Summary

Piotr needs five branches to repair his cart. The quest is offered only after the player has resolved `sporne-drewno` in Piotr's favour, or has delivered wood to Anna in `drewno-dla-anny`. If the cart is already repaired, the quest ends as `already_repaired`.

## Stages / objectives

- Gather 5 `branch` items (`gather_item`, count 5).

## Outcomes & rewards

- `delivered_to_piotr` (complete, reward shown): 8 coins and relation +1 with Piotr.
- `already_repaired` (complete): no reward.
