# Quaternius UBC subset (repo-local)

Minimal **CC0 1.0** subset of Quaternius Universal Base Characters [Standard],
vendored so custom NPC compose does not depend on `_temp/`.

| Path | Role |
|------|------|
| `ubc-base/Superhero_Male_FullBody.*` | Male body; eyes/eyebrows meshes; head-slice source |
| `hair/Hair_SimpleParted.*` | Default male hair (runtime attachment) |
| `hair/Hair_Long.*` | Long male hair (runtime attachment; `T_Hair_2_*`) |
| `hair/Hair_Beard.*` | Optional beard (runtime attachment) |
| `outfits/Quaternius_Outfits_All_Male.blend` | Blender master for modular outfit authoring |
| `License_Standard.txt` | Pack license (CC0 1.0) |

Do **not** vendor the full UBC or Fantasy packs here. Add only the exact
hair/base files a new custom NPC variant needs.

Upstream: https://quaternius.com/packs/universalbasecharacters.html
