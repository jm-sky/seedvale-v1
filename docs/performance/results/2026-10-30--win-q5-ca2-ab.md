### CA2 `stream` — post-hoc tail attribution (existing raw data, no new runs)

Added 2026-10-30 by Opus from the same four `win-ca2-*-stream-rep1` reports (`.md` long-frame / program sections, `.json` `longFrames.worst`, `.raw.json` frames). The author's benchmark session was interrupted; no further `stream` reps exist.

- **Grass is absent from every attributed tail event.** In all 20 worst frames (5 per run, both arms) `GRASS` ≤ 0.1 ms; no run has a grass hitch (`>= 8 ms` hitches are only `chunk mesh` / `chunk water` / `chunk vegetation`); grass finalization callback max ≤ 1.0 ms in both arms. CA2 regrowth is visible only as more, equally cheap, builds (B1 28 vs A 19 per species bucket).
- **The worst frames are the same two families in both arms:**
  1. `WATER` 200–400 ms inside `render` — first draw of a newly streamed program in the **water mirror pass** (program-compile section: `MapleTree_Bark` / `maple_1.glb` 209–396 ms in A1, B2, A2; `Male_Peasant` `MI_Eyes` 204 / 721 ms at B1/B2 window start). Plan 149 Phase 1 A prewarms only programs present at load; streamed families still pay first use mid-travel.
  2. Synchronous `riverTileBuild` 37–128 ms (`chunkUpdate` → `retainRiverTilesFor`, `src/terrain/chunkManager.ts`), sometimes in the same frame as an `NPC`/`FAUNA` spike of 64–180 ms.
- **Program census is equal across arms** (129–130 programs), so CA2 does not add shader variants. The B runs compiled ~8 programs (incl. `MI_Eyes`) in their first ~20 frames instead of before the window; B's first 30 frames cost ~830–870 ms vs ~630–660 ms in A, and the 3 s-window median is worse in B from the first window on — before CA2 regrowth can matter.
- The remaining B-side shift (more 80–170 ms frames, `FAUNA` system mean 2.5–2.6 vs 1.3–1.8 ms, `WATER` 2.6–2.9 vs 2.0–2.2 ms) touches systems CA2 does not run; with the forest A1 outlier (63 vs ~42 FPS) showing the session's spread, it is not attributable to CA2 from this data.

**Updated reading: no evidence of a CA2-caused regression; the `stream` tail is dominated by mirror-pass first-use compile and sync river tile builds in both arms.** Recommendation: keep the flag on and fold an n ≥ 3 `stream` retest into the next batched Windows session (Q7 P1 exit packet) instead of a dedicated rerun. The author decides (queue §3).
